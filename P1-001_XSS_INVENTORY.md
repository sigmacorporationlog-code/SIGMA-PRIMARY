## Extended dynamic-construction scan

A complementary scan was performed beyond classic HTML sinks. The scan covered `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, dynamic `href/src`, inline HTML event attributes, template-string interpolation, JSON embedded in HTML attributes, `javascript:` / `data:text/html` URL constructions, and dynamic CSS/style values.

Baseline H4 extended-scan observations:
- 183 total suspicious DOM/HTML construction hits before semantic classification.
- Classic HTML/DOM sinks inventoried above: 87.
- Dynamic `href/src` constructions requiring context review: 3.
- Inline HTML attribute interpolation patterns: 2.
- `javascript:` URL constructions: 0 detected.
- `data:text/html` constructions: 0 detected.

The extended count is intentionally not treated as the number of vulnerabilities: each occurrence was classified by sink context and data provenance.


## Remediation result — P1-001

The baseline `REQUIRES_ESCAPE` cases were reviewed and remediated without blanket replacement of every `innerHTML` sink. The principal controls are:

- `Sigma.escapeHtml()` for text inserted into HTML contexts.
- Numeric coercion (`Number(...)`) for DOM identifiers and numeric attributes.
- `encodeURIComponent(JSON.stringify(...))` for structured data carried through `data-*` attributes instead of inline JavaScript.
- DOM event listeners for previously dynamic inline handlers.
- `Sigma.safeCssHexColor()` for CSS color/style values.
- Central CSP middleware in `app/main.py`, with `unsafe-eval` absent. `unsafe-inline` remains temporarily justified because the current static frontend still contains inline scripts/styles and a limited number of static/escaped handlers.

Post-remediation evidence:
- P1 static/security tests: **4/4 PASS**.
- P1 runtime Node payload test: **1/1 PASS**, covering 7 XSS payload classes plus the CSS-color guard.
- Inline JavaScript syntax: **20/20 HTML pages PASS** with `node --check`.
- Search for `javascript:` and `data:text/html`: **0 occurrences**.
- Dynamic object JSON embedded directly in `onclick`: **0 occurrences**.
- Remaining dynamic inline handlers: numeric/static identifiers or explicitly HTML/JS-escaped strings; no raw business object JSON embedding identified.

Residual qualification limitation:
- Browser-level Chromium execution could not be completed in the current container. The installed `/usr/bin/chromium` did not terminate successfully in headless mode; therefore no browser-runtime PASS is claimed. P1-001 remains **PARTIALLY VERIFIED**, not CLOSED, until a real browser execution is obtained.
