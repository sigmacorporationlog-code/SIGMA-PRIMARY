# SIGMA Primaire — Release 1.0.0

## Dossier administratif imprimable

- Attestation d'inscription PDF par élève.
- Dossier administratif PDF regroupant identité, responsables et historique scolaire.
- Contrôle strict de l'établissement sur les documents.
- Journalisation des générations de documents.
- Conservation de l'historique des inscriptions.

## Limites

Cette version ne prétend pas encore reproduire à l'identique les carnets officiels MINEDUB. Cette reconstruction fera l'objet d'un chantier dédié après validation des sources officielles.
