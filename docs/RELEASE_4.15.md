# SIGMA V4.15 — AI Trusted Answers

## Objectif
Renforcer la fiabilité des réponses documentaires de SIGMA AI.

## Fonctionnalités
- mode `grounded_only` configurable ;
- seuil minimal de pertinence documentaire ;
- citations exposées dans la réponse API ;
- pondération de pertinence affichée ;
- refus contrôlé lorsqu’une question explicitement documentaire ne dispose d’aucune source publiée pertinente ;
- les outils opérationnels (finance, assiduité, pédagogie) restent utilisables sans document institutionnel ;
- contenu documentaire externe toujours désactivé par défaut.

## Sécurité
Le mode strict réduit le risque d’hallucination sur les règlements, procédures, contrats et politiques internes. Il ne constitue pas une garantie absolue : les utilisateurs doivent vérifier les réponses sensibles.
